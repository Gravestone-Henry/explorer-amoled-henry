#  AMOLED Explorer

> Um gerenciador de arquivos moderno, leve e minimalista com tema **AMOLED (Preto Absoluto)**, desenvolvido em Python utilizando **PyQt6**. Criado para oferecer uma experiência visual imersiva e economia de energia em telas OLED, com recursos avançados de customização.

---

##  Funcionalidades

- **Tema AMOLED (Preto Absoluto `#000000`):** Interface pensada para reduzir o cansaço visual e destacar os elementos neon.
- **Paleta de Cores Dinâmica:** Seletor de cores livre (`Color Picker`) para você personalizar a cor de destaque (accent color) do aplicativo com qualquer tom que desejar.
- **Barra de Acesso Rápido:** Atalhos laterais para pastas comuns do sistema (Área de Trabalho, Documentos, Downloads, Imagens, Vídeos e Disco Local).
- **Navegação Completa:** Árvore de diretórios (TreeView) e Tabela de arquivos (TableView) integradas, com suporte a histórico (Voltar, Avançar, Subir nível e Início).
- **Gerenciamento de Arquivos:** 
  - Criação rápida de novas pastas e arquivos diretamente pela interface.
  - Menu de contexto (botão direito) para Abrir, Renomear e Excluir itens com confirmação de segurança.
- **Portátil (.exe):** Pode ser compilado em um único executável independente.

---

##  Tecnologias Utilizadas

- **Python 3**
- **PyQt6** (Framework para interface gráfica)
- **PyInstaller** (Para empacotamento em executável)
